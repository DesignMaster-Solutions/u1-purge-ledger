**Update, 12 November: two full-size prints, and which colour pair costs most.**

Until now the ledger had only seen small files. @Mr.Borispol posted two of his real projects in [the dock thread](https://forum.snapmaker.com/t/43745/21), so I ran the ledger on both. They are my slices of his .3mf in Snapmaker Orca 2.4.1, with the prime tower moved for the other test, so the grams below are for those slices, not for the files he printed.

| | tool changes | tower | whole print | slicer trailer |
|---|---|---|---|---|
| KOI fish, 3 colours | 453 | 41.45 g | 437.71 g | 437.72 g |
| Bounding Bunny plate 3, 4 colours | 186 | 20.52 g | 417.28 g | 417.29 g |

The totals match what the slicer writes at the end of the file, to 0.01 g, on 216 and 223 MB of G-code.

Two things changed in the tool because of these files ([bdcdbe8](https://github.com/DesignMaster-Solutions/u1-purge-ledger/commit/bdcdbe8), release [v1.0.2](https://github.com/DesignMaster-Solutions/u1-purge-ledger/releases/tag/v1.0.2), and the [site](https://designmaster-solutions.github.io/u1-purge-ledger/) already runs it):

**1. One line per colour pair, heaviest first.** A table with 453 rows does not tell you where the filament goes. The report now ends with this (KOI):

```
T2>T1 x124 = 8.52 g
T1>T2 x121 = 8.31 g
T0>T2 x104 = 7.17 g
T2>T0 x101 = 6.93 g
T1>T0 x3   = 0.24 g
```

Another 10.28 g is the tower walls on the 246 layers that have a change. T2 is in all four expensive pairs, so on this fish that is the colour to look at first if you want fewer changes.

**2. Big files.** The ledger used to hold the whole file in memory: 1.4 GB for the KOI. It now reads line by line, 18 MB, 13 s instead of 88 s on the command line, same totals.

**Not checked:** I have not dropped a 216 MB file on the site in a browser (only the command line was measured), and neither print was weighed. If anyone prints a multi-colour file and puts the tower on a scale, the number next to the ledger's "tower" line is the check I cannot do without the printer.
